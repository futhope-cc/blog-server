# 1. 项目概述

## 1.1 项目名称

个人技术博客与项目展示平台

## 1.2 项目背景

打造一个集技术博客、项目展示、知识沉淀和个人品牌建设于一体的技术型个人网站。

主要用于：

-   技术文章沉淀
-   项目成果展示
-   技术能力证明
-   开源项目推广
-   个人技术品牌建设
