# 个人博客后台管理接口对接文档

> **Base URL**: `http://localhost:8081/api`（可由 `public/config.js` 的 `apiBaseUrl` 覆盖）
> **数据格式**: `application/json`（除分页查询用 query 参数、文件上传用 multipart/form-data 外，其余 POST/PUT 均为 JSON body）
> **关联文档**: 用户模块接口详见《用户模块接口对接文档.md》

---

## 一、通用约定

### 1.1 统一返回格式

所有接口统一返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- `code`: 0=成功，非0=失败（401=未登录，前端会清除登录态并跳转登录页）
- `message`: 描述信息
- `data`: 业务数据，失败时为 null

### 1.2 鉴权方式

- 登录成功后返回 `tokenValue`，存本地存储
- 所有需鉴权接口在请求头携带：`satoken: <tokenValue>`

### 1.3 分页说明

- **用户模块**：MyBatis Plus 格式，`data = { records, total, current, size }`
- **文章/项目/文件模块**：当前前端约定 `data = { total, list }`，待与后端对齐（建议后端统一返回 MyBatis Plus 格式时同步改造前端）

## 三、文章管理

### 3.1 分页查询文章列表

- **URL**: `GET /admin/article/list`
- **鉴权**: 是

**请求参数**(Query String):

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| page | long | 否 | 1 | 当前页码 |
| pageSize | long | 否 | 10 | 每页条数 |
| keyword | string | 否 | - | 标题/摘要 模糊搜索 |
| categoryId | long | 否 | - | 分类 ID |
| tagId | long | 否 | - | 标签 ID |
| status | string | 否 | - | draft=草稿 published=已发布 offline=已下线 |

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 7,
    "list": [
      {
        "id": 1,
        "title": "FFmpeg 音视频转码实战",
        "summary": "介绍 FFmpeg 常用命令与优化技巧。",
        "content": "## Markdown 正文",
        "cover": "",
        "categoryId": 4,
        "categoryName": "音视频",
        "tagIds": [1, 5],
        "tagNames": ["FFmpeg", "GB28181"],
        "viewCount": 1286,
        "status": "published",
        "createTime": "2026-07-12T09:30:00",
        "publishTime": "2026-07-12T09:30:00"
      }
    ]
  }
}
```

### 3.2 文章详情

- **URL**: `GET /admin/article/{id}`
- **鉴权**: 是

**路径参数**: `id` (long) 文章 ID

**响应数据**: `data` 为单篇文章对象（同列表元素，含完整 `content`）

### 3.3 新增/编辑文章

- **URL**: `POST /admin/article`
- **鉴权**: 是

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | long | 否 | 有则编辑，无则新增 |
| title | string | 是 | 标题 |
| summary | string | 是 | 摘要 |
| content | string | 是 | Markdown 正文 |
| cover | string | 否 | 封面图 URL |
| categoryId | long | 是 | 分类 ID |
| tagIds | long[] | 否 | 标签 ID 列表 |
| status | string | 是 | draft=存草稿 published=发布 |

**响应数据**: `data` 为保存后的文章对象

### 3.4 删除文章

- **URL**: `DELETE /admin/article/{id}`
- **鉴权**: 是

**路径参数**: `id` (long)

**响应数据**: `data = null`

### 3.5 变更文章状态（发布/下线）

- **URL**: `PATCH /admin/article/{id}/status`
- **鉴权**: 是

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| status | string | 是 | published=发布 offline=下线 |

**响应数据**: `data` 为更新后的文章对象

## 四、分类管理

### 4.1 分类列表（含文章数）

- **URL**: `GET /admin/category/list`
- **鉴权**: 是

**请求参数**: 无

**响应数据**: `data` 为分类数组，按 sort 升序
```json
{
  "code": 0,
  "message": "success",
  "data": [
    { "id": 1, "name": "C++", "sort": 1, "articleCount": 1, "createTime": "2026-01-05T09:12:00" }
  ]
}
```

### 4.2 全部分类（下拉用）

- **URL**: `GET /admin/category/all`
- **鉴权**: 是

**请求参数**: 无

**响应数据**: `data` 为分类数组（无 articleCount）

### 4.3 新增/编辑分类

- **URL**: `POST /admin/category`（新增）/ `PUT /admin/category/{id}`（编辑）
- **鉴权**: 是

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 分类名称（唯一） |
| sort | int | 是 | 排序值 |

**响应数据**: `data` 为保存后的分类对象

### 4.4 删除分类

- **URL**: `DELETE /admin/category/{id}`
- **鉴权**: 是

**路径参数**: `id` (long)

**响应数据**: `data = null`

> 业务限制：该分类下存在文章时不可删除

## 七、文件管理

### 7.1 分页查询文件

- **URL**: `GET /admin/file/list`
- **鉴权**: 是

**请求参数**(Query String):

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| page | long | 否 | 1 | 当前页码 |
| pageSize | long | 否 | 12 | 每页条数 |
| type | string | 否 | - | image=图片 file=附件 |
| keyword | string | 否 | - | 文件名模糊搜索 |

**响应数据**: `data = { total, list }`，list 元素：
```json
{
  "id": 1,
  "name": "ffmpeg-cover.png",
  "url": "https://cdn.example.com/2026/07/xxx.png",
  "type": "image",
  "size": 245760,
  "uploadTime": "2026-07-12T09:00:00"
}
```

### 7.2 上传文件

- **URL**: `POST /admin/file/upload`
- **鉴权**: 是
- **数据格式**: `multipart/form-data`

**请求参数**(FormData):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | file | 是 | 上传的文件（支持图片/附件） |

**响应数据**: `data` 为文件对象（同列表元素，图片时 `url` 为可访问地址）

### 7.3 删除文件

- **URL**: `DELETE /admin/file/{id}`
- **鉴权**: 是

**路径参数**: `id` (long)

**响应数据**: `data = null`

## 八、数据统计

### 8.1 仪表盘统计

- **URL**: `GET /admin/stats/dashboard`
- **鉴权**: 是

**请求参数**: 无

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "overview": {
      "articleCount": 7,
      "projectCount": 3,
      "viewCount": 4078
    },
    "trend": [
      { "date": "2026-06-16", "views": 320, "articles": 1 }
    ],
    "categoryDist": [
      { "name": "音视频", "value": 2 }
    ],
    "hotArticles": [
      { "id": 1, "title": "FFmpeg 音视频转码实战", "viewCount": 1286 }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| overview | object | 汇总：文章数/项目数/总浏览量 |
| trend | array | 访问趋势（近 7 周） |
| categoryDist | array | 文章分类分布 |
| hotArticles | array | 热门文章 TOP5 |
