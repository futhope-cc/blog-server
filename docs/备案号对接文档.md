# 备案号对接文档

## 基础信息

- Base URL：`http://localhost:8081/api`
- 前台读取无需鉴权；后台设置需请求头 `satoken: <tokenValue>`
- 统一返回格式：`{ "code": 0, "message": "success", "data": {...} }`

---

## 前台：读取备案号

**GET `/profile`**（公开，无需 token）

返回 `data` 中包含 `copyright` 字段（string，可为 null）：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "1",
    "nickname": "站长",
    "copyright": "粤ICP备XXXXXXXX号",
    "bio": "...",
    "techStack": "...",
    "github": "...",
    "updateTime": "2026-08-18T10:30:00"
  }
}
```

前端展示逻辑：`data.copyright` 有值时显示，为 `null` 或空字符串时不展示。

---

## 后台：设置备案号

**PUT `/profile`**（需鉴权，请求头 `satoken: <tokenValue>`）

请求体（Content-Type: `application/json`）：

```json
{
  "copyright": "粤ICP备XXXXXXXX号"
}
```

说明：只需传 `copyright` 字段即可，其他字段可省略（未传的字段不会被覆盖）。

成功返回：

```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```
