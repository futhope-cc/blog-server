# 用户模块接口对接文档

> **Base URL**: `http://localhost:8081/api`
> **接口文档(Swagger UI)**: `http://localhost:8081/api/swagger-ui.html`
> **数据格式**: `application/json`（除分页查询用 query 参数外，其余 POST/PUT 均为 JSON body）

---

## 一、通用约定

### 1.1 统一返回格式

所有接口统一返回以下 JSON 结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 0=成功，非0=失败（见错误码表） |
| message | string | 描述信息 |
| data | object/null | 业务数据，失败时为 null |

### 1.2 鉴权方式

- 登录成功后，后端返回 `tokenName` 和 `tokenValue`
- 后续所有需鉴权的接口，**必须在请求头中携带 token**：
  ```
  satoken: <tokenValue>
  ```
- token 有效期 30 天，未登录访问受保护接口返回 401

### 1.3 错误码表

| code | message | 说明 |
|---|---|---|
| 0 | success | 成功 |
| 400 | 参数校验失败 | 请求参数不合法 |
| 401 | 未登录 | 未提供 token / token 无效 / token 过期 |
| 403 | 无权限 | 已登录但无权限 |
| 404 | 资源不存在 | 接口不存在 |
| 405 | 请求方法不支持 | HTTP Method 错误 |
| 500 | 系统错误 | 服务端异常 |
| 1001 | 用户名或密码错误 | 登录失败 |
| 1002 | 用户不存在 | 操作的用户不存在 |
| 1003 | 用户已被禁用 | 登录时账号被禁用 |
| 1004 | 用户名已存在 | 新增用户时用户名重复 |
| 1005 | 原密码错误 | 修改密码时原密码不正确 |
| 1006 | 不能删除自己 | 删除操作作用于当前登录用户 |
| 1007 | 不能删除最后一个管理员 | 系统至少保留一个正常用户 |

### 1.4 分页响应格式

分页查询接口的 `data` 字段结构：

```json
{
  "records": [],
  "total": 100,
  "current": 1,
  "size": 10
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| records | array | 当前页数据列表 |
| total | long | 总记录数 |
| current | long | 当前页码 |
| size | long | 每页条数 |

### 1.5 用户信息结构

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 用户ID（字符串类型，避免 JS 精度丢失） |
| username | string | 用户名 |
| nickname | string | 昵称 |
| avatar | string | 头像URL |
| email | string | 邮箱 |
| status | int | 状态: 0=禁用 1=正常 |
| createTime | string | 创建时间（ISO 8601） |

## 二、鉴权接口

### 2.1 登录

- **URL**: `POST /user/login`
- **鉴权**: 否

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| username | string | 是 | 不为空 | 用户名 |
| password | string | 是 | 6-50字符 | 密码 |

**请求示例**:
```json
{
  "username": "admin",
  "password": "123456"
}
```

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "tokenName": "satoken",
    "tokenValue": "a55d90fe-f891-4fe6-9232-d40ec8beebe3",
    "userInfo": {
      "id": "1",
      "username": "admin",
      "nickname": "管理员",
      "avatar": null,
      "email": null,
      "status": 1,
      "createTime": "2026-08-04T10:30:00"
    }
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| tokenName | string | token 名称（请求头 key） |
| tokenValue | string | token 值（请求头 value） |
| userInfo | object | 当前登录用户信息（见用户信息结构） |

> **前端处理**: 登录成功后将 `tokenValue` 存入本地存储，后续请求在 header 中携带 `satoken: <tokenValue>`。

---

### 2.2 登出

- **URL**: `POST /user/logout`
- **鉴权**: 是

**请求参数**: 无

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

> **前端处理**: 登出成功后清除本地存储的 token，跳转登录页。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "1",
    "username": "admin",
    "nickname": "管理员",
    "avatar": null,
    "email": null,

```

---

### 2.4 修改当前用户密码

- **URL**: `PUT /user/password`
- **鉴权**: 是

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| oldPassword | string | 是 | 不为空 | 原密码 |
| newPassword | string | 是 | 6-50字符 | 新密码 |

**请求示例**:
```json
{
  "oldPassword": "123456",
  "newPassword": "654321"
}
```

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

> **注意**: 修改密码后当前 token 仍然有效，如需让用户重新登录，前端可主动调用登出接口。

## 三、用户管理接口

> 以下接口均需鉴权（请求头携带 `satoken`）

### 3.1 分页查询用户

- **URL**: `GET /user/page`
- **鉴权**: 是

**请求参数**(Query String):

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| current | long | 否 | 1 | 当前页码 |
| size | long | 否 | 10 | 每页条数 |
| username | string | 否 | - | 用户名（模糊匹配） |
| status | int | 否 | - | 状态: 0=禁用 1=正常 |

**请求示例**:
```
GET /user/page?current=1&size=10&username=admin&status=1
```

**响应数据**:

```json
  "message": "success",
  "data": {
    "records": [
      {
        "id": "1",
        "username": "admin",
        "nickname": "管理员",
        "avatar": null,
        "email": "admin@example.com",
        "status": 1,

    ],
```

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| username | string | 是 | 2-50字符 | 用户名（唯一） |
| password | string | 是 | 6-50字符 | 初始密码 |
| nickname | string | 否 | - | 昵称 |

**请求示例**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |

### 3.4 删除用户

- **URL**: `DELETE /user/delete/{id}`
- **鉴权**: 是

**路径参数**:

| 字段 | 类型 | 说明 |
|---|---|---|
| id | long | 用户ID |

**请求示例**:
```
DELETE /user/delete/2
```

**响应示例**:
```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

> **业务限制**:
> - 不能删除当前登录用户（返回 1006）
> - 系统至少保留一个正常状态用户（返回 1007）
> - 逻辑删除，数据不会从数据库物理删除

## 五、前端对接要点

### 5.1 Token 管理

```
1. 登录 → 拿到 tokenValue → 存入 localStorage/cookie
2. 请求拦截器 → 从存储中取出 → 设置 header: satoken = tokenValue
3. 响应拦截器 → code=401 → 清除 token → 跳转登录页
4. 登出 → 调用登出接口 → 清除本地 token → 跳转登录页
```

### 5.2 axios 请求拦截器示例

```javascript
// 请求拦截器：自动携带 token
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('tokenValue')
  if (token) {
    config.headers['satoken'] = token
  }
  return config
})

// 响应拦截器：统一处理 401
axios.interceptors.response.use(
  response => {
    if (response.data.code === 401) {
      localStorage.removeItem('tokenValue')
      router.push('/login')
      return Promise.reject(response.data)
    }
    return response.data
  },
  error => Promise.reject(error)
)
```

### 5.3 用户 ID 精度问题

后端返回的用户 `id` 字段为 **string** 类型，已处理 JS 大数精度问题，前端可直接作为字符串使用，无需额外处理。
